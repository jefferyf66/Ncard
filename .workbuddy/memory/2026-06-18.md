# 2026-06-18 工作日志

## 分享气泡卡片 Bug 修复（P0）

**问题**：分享气泡卡片时接收方无法看到卡片内容

**根因**：`edit/index.js:_generateAndStoreShareImage()` 将 `shareImageUrl` 存储为直接 HTTPS CDN URL（`STORAGE_BASE + cloudPath`），绕过微信 cloud:// 协议认证。云存储设为"仅创建者可读写"时，接收方无法通过 CDN 直接访问 → HTTP 403 → 气泡图片空白。

**修复内容**（2 文件，3 处变更）：
1. `pages/edit/index.js:448-461` — `_generateAndStoreShareImage`：shareImageUrl 改用 `uploadRes.fileID`（cloud:// 格式），移除 `STORAGE_BASE` 硬编码
2. `pages/index/index.js:483-495` — `_resolveAvatarUrl`：不再调用 `app.resolveCloudFileIDs()` 转换 cloud:// → HTTPS，直接保留 cloud:// 由微信自动做权限代理
3. `pages/index/index.js:497-522` — `onShareAppMessage`：增加新旧 URL 格式兼容注释

**原理**：微信基础库 2.8.1+ 原生支持 cloud:// 作为 `onShareAppMessage` 的 `imageUrl`，接收方打开时微信会自动解析为带鉴权的临时 URL，不受云存储 ACL 限制。

**附加发现**：`app.js:resolveCloudFileIDs()` 也是直接 HTTPS URL 转换，影响 `list/index.js` 和 `preview/index.js` 的头像显示（非分享流程），本次未修复，单独跟踪。

**分析报告**：`artifacts/share-bubble-bug-analysis.md`

## 分享气泡卡片 Bug 修复 — 第二轮修正

**用户反馈**：云存储权限为「所有用户可读，仅创建者可读写」，HTTPS URL 不是问题。

**重新分析 → 真正根因**：**时序竞态**
- `saveCard()` 中 `navigateBack` 在 1500ms 触发
- `_generateAndStoreShareImage` 链 `800ms delay + Canvas+上传+DB ≈ 2800ms`
- 导航回首页时 Canvas 被销毁 → `shareCard.generate()` 失败被静默吞掉
- 结果：`shareImageUrl` 从未成功写入 DB → 分享时降级到头像 → 接收方看不到分享卡片图

**第二轮修复**（2 文件，重写核心逻辑）：
4. `pages/edit/index.js:403-426` — saveCard 改为 Promise 链等待分享图生成完成（15s 超时），delay 从 800ms→100ms
5. `pages/edit/index.js:429-491` — `_generateAndStoreShareImage` 返回 Promise，3 种失败路径可控，shareImageUrl 用 cloud://
6. `pages/index/index.js:498-548` — `onShareAppMessage` 三层降级：预存→实时生成+上传(cloud://)→头像兜底

**总计修改**：5 处变更覆盖 edit/index.js 和 index/index.js，含完整时序修复 + 实时生成兜底

**用户关键反馈**："标题降级为小程序名"，不仅是图片问题。

## 分享气泡卡片 Bug — 第六轮（图片体积 + downloadFile 域名）

**参照豆包分析**，两个致命问题：

### 1. 图片体积超 128KB（微信硬限制）
- `shareCard.js:517` — `fileType: 'png'`，600×480 PNG 含文字渐变头像可达 150-300KB
- 微信服务器抓取图片时，>128KB 直接丢弃 → 接收方看到空白
- **修复**: `fileType: 'jpg'`, `quality: 0.7` → 预计 30-50KB

### 2. downloadFile 合法域名（必须配置！）
- 分享图片通过微信 downloadFile 接口拉取，CDN 域名必须在后台配置
- 域名: `https://636c-cloudbase-d0gqgpu422d7e544f-1432712671.tcb.qcloud.la`
- **用户需操作**：MP后台 → 开发管理 → 开发设置 → downloadFile合法域名 → 添加该域名
